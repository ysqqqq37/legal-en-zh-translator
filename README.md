# 法律英汉双向翻译 Skill

面向法律英语与中文互译，尤其关注普通法合同。这个 Skill 通过 `SKILL.md` 向宿主模型提供翻译与核对指引；仓库不含独立翻译服务、术语检测程序或自动审校程序。

## 安装与使用

1. 下载或克隆本仓库，将整个目录放入你所用、支持自定义 Skill 的工具的 Skill 目录。保留 `SKILL.md`、`references/`、`agents/` 和 `assets/` 的相对位置。
2. 在工具中启用或调用 `legal-en-zh-translator`。例如：“请使用 legal-en-zh-translator 翻译以下合同条款，并标注影响理解的歧义。”
3. 提供待译文本、翻译方向，以及已知的原文法域、文书类型和目标读者。涉及保密材料时，先确认所用工具及检索方式符合你的保密要求。

`SKILL.md` 是入口；`references/jurisdiction-and-terms.md` 提供法域与术语提醒，`references/qa-rubric.md` 是译前交付核对清单，`agents/openai.yaml` 和 `assets/icon.svg` 提供界面元数据及图标。各工具的 Skill 安装位置和调用方式可能不同，请以所用工具的说明为准。

## 六步流程

1. **确定翻译框架：**识别英译中或中译英、文书类型、读者和已知原文法域；法域缺失且影响含义时提问或注明暂译。
2. **按条款拆分：**保留编号、定义和交叉引用；长文维护术语记录，标出缺失附件。
3. **核对条款逻辑：**逐项保留主体、权利义务、条件、期限、例外、后果及数字，不机械处理 `shall`、`may` 等词。
4. **处理法域术语：**遇到不等值概念时参照术语文件，必要时保留原词，避免把原文法律制度悄悄改写成目标语言地区的制度。
5. **做语义核对：**按 QA 清单回看原文，纠正误译，单独记录仍未解决的原文歧义；需要查证法律含义时使用相关法域的现行一手资料。
6. **按用途交付：**先给译文，再视需要给简短术语与歧义说明；双语审阅指出具体差异。实质性改写须另行明确请求并与翻译分开。

## 能力边界

- 翻译、翻译审阅与法律改写是不同任务；本 Skill 默认追求忠实翻译，不保证条款有效或可执行。
- 不提供认证翻译、律师签署意见、准确率保证，也不代表人工专家审校。用于签署、提交或处理重大法律歧义时，应安排相应专业复核。
- 法域、版本、缺失附件或原文歧义可能限制结论；无法核验权威资料时应说明限制，不编造来源。
- 不应将保密合同原文直接发送到公开搜索或外部翻译服务；查询公开法律术语、法规或案例时应避免披露客户材料。
